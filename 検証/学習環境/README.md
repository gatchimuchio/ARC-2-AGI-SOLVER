# 第一増分の検証結果

## 目的と採否

ARCの専用HDS学習機械を経験で育て、コンペ満点を目指す。今回確認したのは教材・学習・評価境界と限定的な継続転用であり、最終目的は未達。公開課題の能力改善はHOLD。45試験・独立差分監査・公開6課題実測により環境増分はADMIT。得点改善と最終目的は未達。

## 実行結果

- 新設試験45/45 PASS
- 同じ新設試験を基点の旧HDSで実行すると36/45 PASS、9件FAIL（新機構要件）
- 旧READMEに記された46試験は原試験がないため再現していない
- 環境監査、compileall、差分空白監査は合格
- 小さな機構対照: 学習前0/1 → 3経験後1/1、記憶除去0/1
- 後続課題の機構対照: 保持は2経験、初期化は3経験で未見値へ適用
- これは設計した支持閾値下で状態の因果作用を確認した可否試験。一般的な学習速度向上を示す結果ではない

## 公開教材

無選別先頭8課題では、全例が36セル予算内なのは2課題、6課題は一部予算外。旧HDS学習後0/8、現行HDS学習前0/8 → 後0/8。

追加実験は、公開training先頭100課題を事前に固定した格子36セル・train 3〜8例という条件だけで走査。6課題を採用、94課題を除外。6課題を同一HDSで連続実行し22経験を保持したが、学習前0/6 → 後0/6、課題毎初期化対照0/6、記憶除去0/6。公開課題での有効な転用と得点改善は未成立。

この部分集合はARC-AGI-2 evaluation全数やコンペ得点ではない。最終公開testの出力は学習状態へ渡していない。予測未閉包、候補競合、誤予測を正答へ読み替えない。

## レビューで修正した境界

- 教示権限を予測した機械インスタンスと状態署名に束縛。別機械・課題切替後・内部更新後の古い予測では教示不可
- 適用範囲外の形状を転用反例として誤隔離しない
- 学習照会は唯一変更される識別子だけ複製し、全台帳の重複複製を避ける。全複製版との予測一致と状態不変を確認
- 課題毎の累積全状態二重保存をやめ、各段階の署名・経験・原理参照と最終checkpoint1本で追跡。経験・原理・反例は削除していない

数値・実装署名・教材hash・状態差は `検証結果.json`、選択と除外理由は `教材固定*.json`。実行手順は `接続/学習環境/README.md`。

## 次の一般機構上の不足

現在の固定セル・値対応表現は偶然相関を大量に候補化し、未見例で競合する。条件値ごとの支持不足、適用範囲、関係合成、計算・記録量を順に調査する。特定課題の解法を外から注入せず、機械自身の導出・棄却・再利用を測る。コンペ満点の目標は未完了として維持する。
