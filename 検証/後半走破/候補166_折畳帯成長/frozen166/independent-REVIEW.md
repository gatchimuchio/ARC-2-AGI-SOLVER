## Source proof

- Every width from 1 through the smallest source width is considered; precisely those dividing every width proceed. There is no width ranking, winning-width selector or candidate count cutoff.
- Shared reflection parity, exact row reflection, every strip's nonempty foreground, shared strip-index bounds, positive integer affine displacement and constant height are checked using all source patches. At least three total strip indices and two noninitial indices are required. These are declared grammar restrictions, not post-fit candidate pruning.
- The initial strip's binary mask is checked across all sources and each initial strip must be monochrome. The pigment cycle uses the explicitly inherited minimal-prefix-period primitive. This is the sole declared pigment-cycle grammar; the proposal does not enumerate every longer compatible pigment period and does not claim that broader completeness.
- Every repeated-template cell is checked against every outer-strip observation. All phases of the fixed pigment cycle satisfying these observations are retained. Background/foreground mask equality is independently enforced.
- A phase assignment changes only the value of its own template cell. Strip column intervals are disjoint and reflection maps each output cell to one half-cell. Therefore the Cartesian product of phase assignments has no cross-cell ownership conflict: taking each future cell's value set is exactly the unanimity test over all assignments. A nonsingleton set returns future failure, never a selected phase.
- Before retention, build reconstructs every complete source patch including background and gaps. At this point each retained phase is already constrained to equal every relevant observed source value, so cellwise consensus cannot discard an otherwise source-fitting assignment. Failed source reconstruction means the width is not source-fitted.
- After full source fit, every width gets a record. Future divisibility, parity, radial extent, bounds or phase-consensus failure increments incomplete_models. No future-failed width is dropped from that count. Both internal axes and every D4 view feed the existing aggregate, which emits only one distinct raster and zero incomplete models.
- New function and aggregate contain no external reads, query identifiers, target constants, target-dependent routes, exception fallback, scorer or answer map. Numeric constants define geometry/indexing or declared witness minima. README documents inspection of a sanitized source pattern; the audit itself did not open any sanitized input, original query or target.
