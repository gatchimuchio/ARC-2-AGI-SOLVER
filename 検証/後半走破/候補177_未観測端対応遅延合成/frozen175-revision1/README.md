# 175: 未観測端方向束縛の明示的合成事前仮説

目的: 151の教師と入力だけから、既存端投射が保持する理由を特定し、未知の特徴キーだけを既存peer関係で補えるか検証する。

## 結果

- 基底: accepted167 `4b67e4f31ecf4c214408c7f642ccdd3738b30641`。基底・HDS中核・全体採否は無変更。
- 元端投射は唯一の教師整合特徴「物体サイズ」を保持。既知表は 3/7/9→top、4/5/11→bottom。
- q0ではサイズ12と6だけが未知。既存HDS照会はその2物体で予測なしの断定保留。既知の3物体はすべてHDS出力が確定している。元候補の失敗は「物体方向がHDSで未確定」。
- 151の全教師適合モデル2個（8連結、色非依存、縦方向、peer→top、回転群またはD4群）が両未知キーへbottomを与え、既知キーとの矛盾なし、物体所有一致、全配置成功。
- q1は全キー既知。新候補は元候補へそのまま委譲する。正解照合はしていない。

## 最小契約

`MissingEdgeBindings` は元教材を保持し、元教材の学習をそのまま実行する。対象は**元特徴モデルが厳密に1個**の場合のみ。0個または複数なら全元モデルを元候補へそのまま委譲する。既知表が入力全体を覆う場合も、元候補の成功・失敗をそのまま返す。

未知キーがある場合、全教師適合peerモデルを実行し、どれか一つでも失敗すれば保留する。軸と物体所有を一致させ、全モデルの物体ごとの方向一致、既知キー整合、同じ未知キーを共有する全物体の整合を要求する。既知キーは元HDSの出力条件を維持する。未知キーに既存HDS予測がある場合も上書きしない。元の配置関数で描画し、その失敗を保持する。結果は全peer描画とも一致する必要がある。

束縛は一回の予測内でのみ作成し、教師表、モデル集合、HDS記憶へ書き込まない。全既知表は不変。異なるキーの未知物体間に新しい教師例を捏造しない。

これはHDSが未確定とする値へ**新しいARC側推論事前仮説**を加える独立候補であり、透過修復ではない。元候補の失敗を成功peer出力の選択で隠すものでもない。将来の統合時は、この合成を明示した候補責任と既存全体採否が必要。現段階でruntimeへの登録、旧候補の置換、全体合意の変更は一切行っていない。
