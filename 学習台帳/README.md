# ARC2規則台帳 v1

固定比較点 d21ecb838bcf77dfc9e7f045ac066000657e2723 の67比較記録を、全原文・出典commit/blob・JSON PointerとUnicode code-point spanで追跡できる共通schemaへ写したものです。

この登録件数は67比較系統であり、HDSが発見した独立原理の個数ではありません。原文の条件・否定・留保は全文保存しています。比較原文だけで不明な主要条件は現行固定コードの行spanで補足し、HDS実採用はfresh baselineのfamily記録を別出典として保持します。コード契約・baseline実測・新しい規則経験再観測を混同しません。比較原文未記録と全出典確認後の未記録を分け、いずれも機能不存在を断定しません。

## 再観測境界

既存の外部入力に対し、内容には原文の規則記述/guardの全leaf文字列を同じ出典leafにつき一度だけ投影します。評価・対照実行報告・支持数診断等は全量を対象archiveに保持し、推論内容には投影しません。この試験は完全経験を保存しつつ、推論特徴は規則記述に限定した観測です。同じ原文leafを複数fieldにコピーして人工的な同値を作りません。独立した原文leaf間の自然な同一文字列は保持し、出典対応へ注記します。出典・ID・由来分類・未知ラベル・外部監査仮説は対象metadata/archiveに残し、推論特徴に入れません。元情報の消失を伴う圧縮ではなく、完全原文を併存するI/O投影です。

文章は現行吸気の下でopaqueな値です。入力に含む文字列や分類と、機械が導出した関係を区別します。索引に「包含」等があることは機械による包含導出ではありません。引用証拠の構造化は実行可能な規則意味論の実装ではありません。

runtime成立Level、最初の失敗点、保存/reload検証、baseline/currentの全格子比較は、検証/学習規則再観測比較.json と 検証/学習規則再観測監査.md に実測として別記します。この生成scriptの成功はruntime成功を意味しません。追加コードの引用は原コードspanを内容へ一度だけ渡し、外部の説明claimは推論内容に加えません。
