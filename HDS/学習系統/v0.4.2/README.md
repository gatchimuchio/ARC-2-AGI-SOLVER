# HDS学習系統 v0.4.2

HDS rev4.2に記述された学習作用を、日本語基底・領域非依存で機械実行するための最小基準機。

```text
外界
↓
最小吸気系
↓
経験保持 → 懐疑 → 候補生成型推論 → 検証・採否 → 適応・状態更新 → 全体帰還
↓
最小排気系
↓
外界
```

実装範囲は候補生成型推論の部分射影であり、比較・共通性、決定的対応、同値関係、反例検出、特殊化、識別不能性、追加観測要求を扱う。

学習成立状態は 成立確認 / 接続途上 / 不成立確認 / 未確認 / 適用外 を区別する。

本実装はHDS総体、人間認知総体、ARC解法の完成を主張しない。
