# HDS学習系統 v0.4.2

HDS rev4.2（内部用統合仕様・正本候補）に記述された学習作用を、日本語基底・領域非依存で機械実行するための最小基準機。

## 系統

```text
外界
  ↓
最小吸気系
  ↓
HDS学習実行系
  経験を保持
    ↓
  懐疑操作「なぜ？」
    ↓
  候補生成型推論
    ↓
  検証・採否
    ↓
  適応・状態更新
    ↓
  全体帰還・再開放
  ↓
最小排気系
  ↓
外界
```

吸気系は外部意味を解かず、排気系は再推論・再採否をしない。中央中核のみが現行実装範囲の学習作用を実行する。

## v0.4.2 の重点修正

第三者による v0.4.1 監査を入力として、以下を修正した。

1. **有効原理の作用と `不成立確認` の自己矛盾を解消**
   - 現行入力に作用可能な有効原理がある場合、広い `不成立確認` を返さない。
   - 既存原理による予測は維持し、その実行で新しい適応がなければ `接続途上` とする。
2. **隔離中の後着反証を審査漏れのまま復帰できないよう修正**
   - 復帰直前に最新の支持・反証を再評価する。
   - 隔離後に到着した反証がある場合、明示的な `審査対象反証参照群` がない限り復帰を拒否する。
   - 復帰時の除外判断は、現時点の全反証を審査した場合だけ当該系譜へ継承する。
3. **原理状態と採用状態を分離**
   - 係争は正本の状態名として追加しない。
   - v0.4.2 の新規記録では `原理状態=適用範囲付き暫定原理` ＋ `採用状態=隔離` とする。
   - `係争中原理群` は互換的な外部表示名であり、正本の原理状態ではない。
4. **学習過程記録を強化**
   - 対象系境界、主体、対象期間、学習前状態スナップショット、保持記憶参照、更新記録参照、観測限界を保持する。
5. **`適用外` を実到達可能化**
   - `照会する` は記憶・懐疑・推論・採否・適応を行わず、現行原理だけで予測する。
   - この経路の学習成立状態は `適用外`。
6. **正本対応表を再構成**
   - 完全対応・部分射影・未実装を明示。
   - 正本19台帳すべてについて対応状態を列挙。

## 「係争中」の意味

`係争中` は外部表示上の便宜語である。v0.4.2 の内部正規表現は次の通り。

```text
原理状態 = 適用範囲付き暫定原理
採用状態 = 隔離
```

旧保存形式の `原理状態=係争中` は読込互換のためだけに残す。新規原理では生成しない。

## 推論の実装範囲

現行の共通推論は **HDSの推論総体ではなく、候補生成型推論の部分射影** である。

実装済み:

- 懐疑の対象経路・要求操作による演算制御
- 比較・共通性
- 単一/複合条件の決定的対応関係
- 同値関係
- 反例検出
- 条件追加による特殊化
- 識別不能性
- 未観測経路・未観測条件値の追加観測要求

未実装:

- 一般的な連想・イメージ生成
- 自律的な懐疑焦点生成
- 意味作用素集合の全射影
- 任意の因果・機構・原理生成
- 任意階数の関係生成

## 学習成立状態

- `成立確認`: 指定対象系・期間で導出内容が後続処理条件へ新たに反映された。
- `接続途上`: 学習作用の一部または既存適応の作用は確認できるが、新しい適応成立までは確認していない。
- `不成立確認`: 指定範囲・現行検査能力で必要な作用または接続の不成立を確認した。
- `未確認`: 観測不足で成立/不成立を確定できない。
- `適用外`: 学習判定を行わない照会実行。
