# 接続

外部世界との互換境界だけをここで扱う。

対象例:

- Kaggle submission format
- ARC Prize公式ファイル名・schema
- Python runtime
- 外部package / API / SDK

内部の学習・判断・診断は日本語を正本とし、外部仕様の固定記号を接続境界で扱う。

- [ARC2接続](ARC2/README.md): 現行学習機械とARC2の教材・解答境界。
- [開発環境](開発環境.md): ローカルPython・依存関係・検証。
- [Kaggle提出](Kaggle提出.md): 認証・Notebook送信・状態・出力・版を指定した大会提出。
