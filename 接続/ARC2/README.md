# HDS・既存機構接続

一つの現行HDSへ、既存のテンプレート穴充填・入れ子パネル合成・閉領域パレット転写と教師由来の物体端投射・凡例穴数対応・色群テンプレート充填・物体群整列・格子自己マスク・辺対応抽出・成分最短経路・対角線橋・対角領域・軸反射・周期組修復の入力専用候補を接続する。充填だけに固定training教材2観測を渡し、入れ子合成・領域転写へ別機構の証拠を混ぜない。全教師再現・採用済み同値原理・既存排気gateが揃う場合だけ出力する。学習後に候補を照会し、採用機構の競合や未確定候補はHOLDとする。

ARCの教師が「異なる入力の二例ちょうど」の場合、呼出側が最小支持数2を設定する。それ以外は3。これは課題全体の証拠要件を3→2へ緩める変更であり、二例での推論確実性が強くなったとの主張ではない。HDS中核の既定値3・検証・反例隔離・排気処理は変更しない。

固定公式source submoduleが必要。単一課題JSONはtrain教師対とtest入力だけを含める。

全120課題・167test例、各課題10CPU秒・512MiB・60秒wall、3並列で旧ARC採点関数を再利用する。baselineモードは初期のHDS格子値診断であり、前commitそのものではない。test正解と課題IDは親採点側に限定する。

前commit `cca0bb0` の50/120課題・70/167例から、凡例集合選択で51/120課題・71/167例へ改善。旧採点器のwrong_attempted_tasksは既存部分回答5課題で不変、誤った出力格子は0。先行70例は全て同一。比較は `検証/凡例集合比較.json`、先行成果は既存比較記録に保持する。

物体端投射は既存8近傍物体抽出と九特徴を使い、教師だけから整合する特徴→上端/下端方向を選ぶ。各物理物体を一度ずつ現行HDSへ観測し、既存bbox順を保つ。未知特徴・識別不能・競合・配置重複は全格子HOLD。予測結果経路の制限は差分0で棄却し、HDS中核は元のまま。

凡例穴数対応の対象色・背景色は教師から選び、穴数と色の関係は現在入力の凡例から読む。不在なら消去する分岐は、課題の最小支持数に達する異なる教師入力が実証した場合だけ許可する。複数の役割候補が異なる格子を出す場合はHOLD。密度0.5以上・長い一セル線の除外は既存の固定heuristicであり、学習結果ではない。

色群充填viewは、全ての現在教師入力で元の充填候補探索が正常終了し候補0件だった場合だけ学習へ進む。教師出力・test・課題IDで適用域を選ばず、非空候補や曖昧候補が一つでもあれば使わない。元探索の例外は伝播する。同色集合と整列した二色集合を全列挙し、既存の同じexact-cover核へ渡す。55群・12部品の固定上限を一つの解釈でも越えればHOLD。受理には適格view全体の一意性を確認し、元kernelの複数解打切りもHOLDとする。

物体群整列は同じ大きさの物体を保存して規則的な枠へ並べるview。既存九特徴・群軸2通り・入力順序軸2通り・昇降順2通りの72候補を全教師で照合し、残った全候補を保持する。物体特徴→群区分は同じHDSへ軸別に観測し、特徴や順序候補で支持を複製しない。未知特徴・群欠落・同率順序・重複対応・候補間不一致はHOLD。出力寸法は現在入力の物体寸法と群個数から決め、二群や特定面積を固定しない。

格子自己マスクは既存の格子分割・色mask・D4を使う新しい限定合成view。頻度による二種類の片の役割2通り・共有/排他色mask2通り・D4の8通りを全教師で照合する。入力seedと整合する全anchorを確認し、一意でなければHOLD。保持した全モデルの完全格子が一致した場合だけ、教師一例につき一度HDSへ渡す。separatorと既存seedを保存し、copyする片は現在入力から得る。旧SELF_MASK_TILEの固定0・全入力二乗展開と同じ実装ではない。

辺対応抽出は内側guide色と外周の同色が多い辺を対応づけ、唯一のD4でpayloadを抽出する既存機構。外周の基準は旧実装の「色個数が最大の辺が一つ」であり、一様性やHDSが学んだ役割規則ではない。新しいguardは背景頻度同率・非一様な内側帯・未解決guide/外周辺を保留する。背景だけの内側帯はguideなしとして扱い、全制約が一つのD4に整合した場合だけ進む。

成分最短経路は旧資産の型付きgraphを使う。4近傍同色成分をnode、8近接をedgeとし、edge数で唯一の最短経路を求める。前景3role・同色同寸法の二つの正方形端点・一辺2以上は固定priorの適用限界。背景同率、role曖昧、非接続、同距離の複数経路はHOLD。二つの新しい出力色は全教師から一致確認して得る値であり、固定3/5ではない。graph node数を支持へ加算せず、教師一例につき最終格子一観測だけHDSへ渡す。

対角線橋は旧priorの「主色の斜めの二点を接続し、途中の別色markerから垂直な対角線を延ばす」機構。主色は全教師を完全再現する一色に限り、固定色ではない。旧教師域は前景14画素以下・前景1〜2色・全教師の色和集合2色以下・各教師1橋。予測域は元実装の主色2〜30画素で、全橋を列挙する。これらの上限や幾何規則をHDSが発見したとはしない。背景は一意とし、元の空白セルへの全ての橋/射影の色提案を先に集め、異色競合はHOLD。先に描いた色の優先を使わず、元の全前景を保存する。橋や画素の数で支持を増やさず、教師一例につき候補格子一観測を同じHDSへ渡す。

対角領域は一色の前景を反対角線s=r+cごとの連続線分へ分け、異なるs上の全線分pairについて、sの間かつd=r−cの共有区間を一つの新色で埋める既存prior。singleton線分も元のまま扱い、方向探索や最初のpairの選択は行わない。充填色は全教師から一意に得て完全格子を再現する。背景同率・複数前景色・入力で充填色が既出ならHOLD。全pairの同色領域和なので描画順の優先はなく、元の前景を保存する。領域や画素数を支持に数えず、教師一例につき最終格子一観測を既存HDSへ渡す。

軸反射は点markerで180度反射、水平/垂直markerで軸反射する既存prior。点のbbox gap3以下、線のspan余白1、完全に空白へ収まる候補の中で最寄りを選ぶ規則は元のheuristicでありHDSの発見ではない。標識色は全教師から選び、保持した全色で完全予測が一致する場合だけ進む。これは旧fitterの一色限定とは異なる合意方針。背景同率・標識形状未対応・最寄りvalid候補同率・適格物体のvalid候補0・異色衝突は全格子HOLD。適格markerがない物体は元の適用域外として保存する。成分とbboxは現在の共有primitiveを使い、教師一例につき候補格子一観測だけを同じHDSへ渡す。

周期組修復は旧priorのpanel分割・一様境界剥離・長い軸のtuple列（同寸ならcolumns）を使う。周期上限6、誤りtuple数max(1,n//3)、(tuple誤差,cell誤差,周期)の優先順は固定のまま。追加した検査器は各位相の全最頻tupleを調べ、唯一の最適列と元rendererの選択が一致した場合だけ元の格子を通す。別のより良い格子への置換はしない。同率・元選択との不一致・予算超過のpanelが一つでもあれば全格子HOLD。今回のcallerは各教師にも非空の確定修復を要求し、旧fitterが許した一部教師の無変更は許可しない。periodやpanelを支持へ数えず、教師一例につき最終格子一観測をHDSへ渡す。

部分見本転写は同寸法の塗り潰し正方形panelと、同色の全外部画素の和集合を対応させる旧prior。非連結の見本も全体を使い、入力内の行列順を保存して外枠と間隔1セルへ正規化し、中央のmaskを背景色で抜く。一辺3以上・最大valid正方形group・固定間隔は既存規則でありHDSの発見ではない。追加guardは一意背景・整数中心・出力30以内を要求し、元のgroup選択後に失敗した場合は小さいgroupへ逃げずHOLD。三つの教師の最終候補格子だけを同じHDSへ観測し、panel数やmask数を支持へ加算しない。

穴形拡大はmapの内部穴と外部のblock完全占有glyphをD4形状で対応づけ、唯一の尺度でmapを拡大する旧prior。候補mapのbbox面積16以上・背景2画素以上、入力各辺6以上、尺度2〜6、有効glyph成分2個以上は固定の適用条件。同形同色の複数glyphも物理成分として数える。catalog色競合はその尺度を無効にし、完全描画できる尺度を一つに限定する。追加guardは一意背景・一意の最大幾何順位・map色だけの外周・map色/背景だけの内部・出力30以内を要求し、失敗後に小mapや別尺度へ逃げない。map選択やD4対応はHDSの発見とせず、二つの教師の最終候補格子だけを同じHDSの同値学習へ渡す。

標識移動は教師の色個数と全格子再現から四色役割を一意に選ぶ旧型付きprior。wallという変数名の色は移動/消去背景で、前方の標識を近い背景帯より優先する。移動量は目的位置までの距離と燃料数の小さい方、燃料変換順も旧実装のまま。追加検査は全物体の解析・一意方向・範囲内・同時色提案の無競合・静止セル保存を要求し、元出力と一致する場合だけ通す。背景接触で標識を消す旧分岐には現在教師の実証を要求し、今回1教師が7画素の消去を示す。これを7支持に数えず、三教師の最終格子だけを同じHDSへ観測する。物理法則の学習や最寄り障害物則とは解釈しない。

放射組立は同色の2cell domino標識とpayloadを対応させ、標識全体の重心から外向きにD4配置する旧prior。横断軸の重心一致・自己標識の全cellへの直交接触に加え、対向境界cell数が最小という固定選好を使う。今回の教師はその選好前に2/4/2通り、適用後に1/1/1通りであり、幾何制約だけの一意性やHDSの発見とはしない。同一D4形状/配置は重複を除き、異なる完全出力・方向同率・探索上限はHOLD。追加guardは全標識と有効色の画素数を保存する。同色標識のない単一shapeを除去する旧分岐には現教師の実証を要求し、今回の8画素除去は1教師の分岐証拠。支持は三教師の最終格子だけとする。

穴輪郭は二色入力から4近傍物体・4近傍の閉じた穴・外側の8近傍輪郭を扱う旧形態prior。背景/物体と新出力三色の全順列を教師で照合し、元rendererの全教師fitが一意であることをguardより先に確認する。背景は最多色と仮定しない。追加guardは本体・穴・外輪郭の異色role重複を保守的に拒否し、元rendererの出力格子と同時提案の一致を要求する。元処理の最終格子には穴優先の順序不変性があり、塗り順依存バグの修復とはしない。入れ子対照では輪郭diagnostic40対48でも実際の輪郭は40画素である。性能増分は形態priorの接続によるもので、支持は10物体ではなく三教師の最終格子とする。

形状色転写は最大templateのbbox背景groupをD4同形のprototypeへ対応させ、物理成分数が唯一最多の色で埋める旧prior。最頻色であって過半数や全会一致を要求せず、2/1/1は通り2/2は保留する。20画素・25bbox面積・3patchという元の閾値は固定制限で、bbox端のpatchも含む。追加guardはBG/main同率を拒否し、最大が不適格でも小templateへ逃げない。prototypeが選択bboxへ入った場合は票を除外せず入力全体をHOLD。入力内の色頻度はHDSの新規発見ではなく、支持も15/31prototypeではなく二つの教師の最終格子である。

凡例経路は入力の水平色列に沿って異なるpanelを選び、payloadの重なる行/列幅でframe間の背景を出発色でつなぐ旧prior。raw抽出で2panel以上を作れる色が一つであることを先に確定し、閉frame・非重複bbox・一つの外部凡例行を検証する。後続失敗で競合役割を捨てない。追加証明は全経路を100,000node以内で尽くし、同格子になる複数経路だけを許す。どれか一経路の異色交差・異なる完全格子・候補発見後の予算超過は全体HOLD。元rendererとの格子一致を要求し、別解へ置き換えない。未使用panelは保存する。これらは固定priorと証明制限でありHDSの新規発見ではなく、native支持は三教師の最終格子だけである。

行周期は縦separatorの片側にある同色run長を周期として、反対の背景側へ重ねる旧符号化prior。位相はseparator隣を0とし、code内の空白gapには依存せず、同時発火はseparatorに近いrunを優先する。部分separator・行ごとの左右activeを元通り許し、code/ separator/ inactive行は保存する。追加guardは有効格子・一意背景・全raw separator一意性を明示するが、複数separatorは元処理もcount tieで拒否するため、曖昧性bugを修復したとはしない。周期と優先をHDSが発見したわけではなく、9行/10衝突の事前確認とは別に、native支持は三教師の最終格子のみである。

重畳組立は8近傍foreground断片のcropを平行移動し、背景も含む完全一致overlapの面積/foreground数で最大spanning treeを選ぶ旧prior。追加証明は採用edgeの最大shift一意性と、各非tree edgeがtree pathの最弱weightより厳密低値であることを要求し、元座標tie-breakの影響を排除する。採用edgeの最大shift同率、または同率最大treeは同じ格子でもHOLD。厳密に低weightな未採用edgeの同率offsetは保持する。全断片の使用・foreignFGなし・30以内の出力・全crop同時一致を確認し、元renderer出力だけ返す。BG→foregroundの後書きも矛盾として拒否する。唯一性は最大overlap prior内のもので、全幾何解やHDSの新規発見とはしない。支持は3/4/6断片ではなく二教師の最終格子である。

`既存象限配色.py` は旧program_searchの3関数を使う。偶数正方形の4象限を固定の符号役割として読み、TL/TRの非0数を出力高さ/幅、BLをpaletteまたはpattern、BRをstencilとする。固定0・位置順序・一画素一単位は旧priorで、背景頻度や学習した寸法規則ではない。

T=BRに非0があれば、周期nのTの非0を描き、0をP=BLのcoarse座標P[(row//n)%n][(col//n)%n]で埋める。一様PをP[0][0]で読む旧scalar枝は同じ式の定数特殊例。Tが全0ならP自体をcell pitchで反復する。これは入力の構造タグであり、描画失敗後のfallbackではない。指定寸法の有限prefixを返すため部分tileも使い、全P/T要素が出力へ現れる保証はしない。全象限の役割解釈と全pixel使用/保存を区別する。

`象限配色教材.py` は新証明・wrapper3関数。全出力座標の所有・色数・元grid/全record一致を確認し、変更しない元格子だけを返す。palette0やtemplateとの同色兼用を許す。guarded_renderでは各辺1..30を旧renderer前に検査するが、教師fitの旧raw再現は先行し、最大225×225のraw出力も実行して不適合を判定する。旧失敗/no-opを別mode・寸法・転置・0の変更で救済しない。

最低2教師は元条件、入力重複拒否とstrict ARC型/出力範囲は追加条件。旧fitterのtest gateは持ち込まず、元全教師再現→証明→同じHDSの各教師盤面という順を守る。教材は適合boolのみを保持し、教師柄やtest outputを予測へ渡さない。nativeは5現在盤面・prior0・min3、mode観測3/1/1やtile/cellを加算しない。既存の全機構合意と情報分離留保を維持する。

## 凡例集合選択

`凡例集合教材.py` は既存の同色/混色component・shape・clone utilityと依存を使う新5関数の組合せ。全色の4近傍同色componentから、canvas隅に接した1cell厚Lの全4向きを列挙し、raw frameが唯一と先決する。その後、全内域の一意modeをBG、残る色の集合をpaletteとする。後段の内域失敗でframeを削って選び直さない。内域tie/frame色alias/空paletteはHOLD。

全体最多BGの初案は第3教師の0=108/地色7=107で不成立と分かり、実装/query前に棄却した。凡例内域modeは明示した新しい固定priorで、背景一般を自動同定したとの主張ではない。色・5×5などの固定サイズ・教師の絶対座標は予測へ埋めない。

元gridの全4近傍混色前景componentは凡例内/外へ完全帰属する必要があり、跨ぎはHOLD。外側はsingletonや非矩形を含め全て処理する。paletteと各成分の色集合の交差/包含/一致×成立/不成立対象の消去という6modelを先決し、全教師共通fitを全保持する。教師では包含消去だけが3盤面を再現した。保持した一候補でも失敗、または完成格子が不一致ならHOLDとし、no-opも全合意後に判定する。

元入力から全対象を決め、選択componentの全cellをBGへ同時消去し、残るcomponent・凡例・元BGを保つ。これは全前景数保存ではない。最低2 distinct教師は追加wrapper条件、保持する学習状態はmodel名だけ。native3現在盤面・prior0・min3で、成分/色/model/画素を支持へ加算しない。既存HDSの全機構合意と情報分離留保を維持する。
