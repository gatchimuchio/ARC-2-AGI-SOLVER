# HDS・既存機構接続

一つの現行HDSへ、既存のテンプレート穴充填・入れ子パネル合成・閉領域パレット転写と教師由来の物体端投射・凡例穴数対応・色群テンプレート充填・物体群整列・格子自己マスク・辺対応抽出・成分最短経路・対角線橋・対角領域・軸反射・周期組修復の入力専用候補を接続する。充填だけに固定training教材2観測を渡し、入れ子合成・領域転写へ別機構の証拠を混ぜない。全教師再現・採用済み同値原理・既存排気gateが揃う場合だけ出力する。学習後に候補を照会し、採用機構の競合や未確定候補はHOLDとする。

ARCの教師が「異なる入力の二例ちょうど」の場合、呼出側が最小支持数2を設定する。それ以外は3。これは課題全体の証拠要件を3→2へ緩める変更であり、二例での推論確実性が強くなったとの主張ではない。HDS中核の既定値3・検証・反例隔離・排気処理は変更しない。

固定公式source submoduleが必要。単一課題JSONはtrain教師対とtest入力だけを含める。

```sh
PYTHONPATH="HDS/学習系統/v0.4.2" python -m 接続.ARC2.HDS接続 < 課題.json
python 検証/ARC2評価.py --mode baseline --output /tmp/arc2-baseline.json
python 検証/ARC2評価.py --mode current --output /tmp/arc2-current.json
python 検証/テンプレート充填回帰.py
python 検証/入れ子合成回帰.py
python 検証/領域転写回帰.py
python 検証/物体端投射回帰.py
python 検証/凡例穴対応回帰.py
python 検証/色群充填回帰.py
python 検証/物体群整列回帰.py
python 検証/格子自己マスク回帰.py
python 検証/辺対応抽出回帰.py
python 検証/成分最短経路回帰.py
python 検証/対角線橋回帰.py
python 検証/対角領域回帰.py
```

全120課題・167test例、各課題10CPU秒・512MiB・60秒wall、3並列で旧ARC採点関数を再利用する。baselineモードは初期のHDS格子値診断であり、前commitそのものではない。test正解と課題IDは親採点側に限定する。

前commit `850e62f` の13/120課題・18/167例から、部分見本転写で14/120課題・19/167例へ改善。旧採点器のwrong_attempted_tasksは既存の部分回答課題1件を数えるが、誤った出力格子は0。比較は `検証/部分見本比較.json`、先行成果は既存比較記録に保持する。

物体端投射は既存8近傍物体抽出と九特徴を使い、教師だけから整合する特徴→上端/下端方向を選ぶ。各物理物体を一度ずつ現行HDSへ観測し、既存bbox順を保つ。未知特徴・識別不能・競合・配置重複は全格子HOLD。予測結果経路の制限は差分0で棄却し、HDS中核は元のまま。

凡例穴数対応の対象色・背景色は教師から選び、穴数と色の関係は現在入力の凡例から読む。不在なら消去する分岐は、課題の最小支持数に達する異なる教師入力が実証した場合だけ許可する。複数の役割候補が異なる格子を出す場合はHOLD。密度0.5以上・長い一セル線の除外は既存の固定heuristicであり、学習結果ではない。

色群充填viewは、全ての現在教師入力で元の充填候補探索が正常終了し候補0件だった場合だけ学習へ進む。教師出力・test・課題IDで適用域を選ばず、非空候補や曖昧候補が一つでもあれば使わない。元探索の例外は伝播する。同色集合と整列した二色集合を全列挙し、既存の同じexact-cover核へ渡す。55群・12部品の固定上限を一つの解釈でも越えればHOLD。受理には適格view全体の一意性を確認し、元kernelの複数解打切りもHOLDとする。

物体群整列は同じ大きさの物体を保存して規則的な枠へ並べるview。既存九特徴・群軸2通り・入力順序軸2通り・昇降順2通りの72候補を全教師で照合し、残った全候補を保持する。物体特徴→群区分は同じHDSへ軸別に観測し、特徴や順序候補で支持を複製しない。未知特徴・群欠落・同率順序・重複対応・候補間不一致はHOLD。出力寸法は現在入力の物体寸法と群個数から決め、二群や特定面積を固定しない。

格子自己マスクは既存の格子分割・色mask・D4を使う新しい限定合成view。頻度による二種類の片の役割2通り・共有/排他色mask2通り・D4の8通りを全教師で照合する。入力seedと整合する全anchorを確認し、一意でなければHOLD。保持した全モデルの完全格子が一致した場合だけ、教師一例につき一度HDSへ渡す。separatorと既存seedを保存し、copyする片は現在入力から得る。旧SELF_MASK_TILEの固定0・全入力二乗展開と同じ実装ではない。

辺対応抽出は内側guide色と外周の同色が多い辺を対応づけ、唯一のD4でpayloadを抽出する既存機構。外周の基準は旧実装の「色個数が最大の辺が一つ」であり、一様性やHDSが学んだ役割規則ではない。新しいguardは背景頻度同率・非一様な内側帯・未解決guide/外周辺を保留する。背景だけの内側帯はguideなしとして扱い、全制約が一つのD4に整合した場合だけ進む。

成分最短経路は旧資産の型付きgraphを使う。4近傍同色成分をnode、8近接をedgeとし、edge数で唯一の最短経路を求める。前景3role・同色同寸法の二つの正方形端点・一辺2以上は固定priorの適用限界。背景同率、role曖昧、非接続、同距離の複数経路はHOLD。二つの新しい出力色は全教師から一致確認して得る値であり、固定3/5ではない。graph node数を支持へ加算せず、教師一例につき最終格子一観測だけHDSへ渡す。

対角線橋は旧priorの「主色の斜めの二点を接続し、途中の別色markerから垂直な対角線を延ばす」機構。主色は全教師を完全再現する一色に限り、固定色ではない。旧教師域は前景14画素以下・前景1〜2色・全教師の色和集合2色以下・各教師1橋。予測域は元実装の主色2〜30画素で、全橋を列挙する。これらの上限や幾何規則をHDSが発見したとはしない。背景は一意とし、元の空白セルへの全ての橋/射影の色提案を先に集め、異色競合はHOLD。先に描いた色の優先を使わず、元の全前景を保存する。橋や画素の数で支持を増やさず、教師一例につき候補格子一観測を同じHDSへ渡す。

対角領域は一色の前景を反対角線s=r+cごとの連続線分へ分け、異なるs上の全線分pairについて、sの間かつd=r−cの共有区間を一つの新色で埋める既存prior。singleton線分も元のまま扱い、方向探索や最初のpairの選択は行わない。充填色は全教師から一意に得て完全格子を再現する。背景同率・複数前景色・入力で充填色が既出ならHOLD。全pairの同色領域和なので描画順の優先はなく、元の前景を保存する。領域や画素数を支持に数えず、教師一例につき最終格子一観測を既存HDSへ渡す。

軸反射は点markerで180度反射、水平/垂直markerで軸反射する既存prior。点のbbox gap3以下、線のspan余白1、完全に空白へ収まる候補の中で最寄りを選ぶ規則は元のheuristicでありHDSの発見ではない。標識色は全教師から選び、保持した全色で完全予測が一致する場合だけ進む。これは旧fitterの一色限定とは異なる合意方針。背景同率・標識形状未対応・最寄りvalid候補同率・適格物体のvalid候補0・異色衝突は全格子HOLD。適格markerがない物体は元の適用域外として保存する。成分とbboxは現在の共有primitiveを使い、教師一例につき候補格子一観測だけを同じHDSへ渡す。

周期組修復は旧priorのpanel分割・一様境界剥離・長い軸のtuple列（同寸ならcolumns）を使う。周期上限6、誤りtuple数max(1,n//3)、(tuple誤差,cell誤差,周期)の優先順は固定のまま。追加した検査器は各位相の全最頻tupleを調べ、唯一の最適列と元rendererの選択が一致した場合だけ元の格子を通す。別のより良い格子への置換はしない。同率・元選択との不一致・予算超過のpanelが一つでもあれば全格子HOLD。今回のcallerは各教師にも非空の確定修復を要求し、旧fitterが許した一部教師の無変更は許可しない。periodやpanelを支持へ数えず、教師一例につき最終格子一観測をHDSへ渡す。

部分見本転写は同寸法の塗り潰し正方形panelと、同色の全外部画素の和集合を対応させる旧prior。非連結の見本も全体を使い、入力内の行列順を保存して外枠と間隔1セルへ正規化し、中央のmaskを背景色で抜く。一辺3以上・最大valid正方形group・固定間隔は既存規則でありHDSの発見ではない。追加guardは一意背景・整数中心・出力30以内を要求し、元のgroup選択後に失敗した場合は小さいgroupへ逃げずHOLD。三つの教師の最終候補格子だけを同じHDSへ観測し、panel数やmask数を支持へ加算しない。

公開評価での改善であり、既存helperの過去開発データから独立な評価・hidden汎化・満点・Kaggle提出を示さない。固定source evaluationのSHA256は既存ZIPマニフェストと不一致であり、source版として評価する。
