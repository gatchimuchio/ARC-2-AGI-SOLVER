# AGI三主体構成

ARC2で用いるAGI構成は次で固定する。

```text
AGI = HDS + ミニドラ（LLM） + 記憶
```

## HDS

ARC2世界を最初に受け取る入力・判断主体。

- 問題入力を観測する
- 対象、関係、目的、問い、境界をFrame化する
- HDSコンパイラでミニドラ用データへ変換する
- ミニドラ出力を評価・反証する
- 必要ならフィードバックして再計算させる
- 最終回答・作用を確定する
- 結果を因果帰属し、記憶更新を採否する

HDSコンパイラはHDS管轄であり、第4主体ではない。

## ミニドラ

LLM主体。HDSがコンパイルしたデータと許可された記憶参照を使い、仮説、反対仮説、推論、計画、命令形、回答候補を生成する。HDSを迂回して確定出力しない。

## 記憶

- Prior Memory: 事前にHDSで完全解析・蒸留した定石と知識
- Runtime Memory: 実行中に得た観測、失敗、因果、補正

を可変保持する。

## 循環

```text
ARC2入力
↓
HDS
↓ HDSコンパイラ
ミニドラ ↔ 記憶
↓
HDS
├ 棄却 → ミニドラへ再入力
└ 確定 → ARC2出力
```
