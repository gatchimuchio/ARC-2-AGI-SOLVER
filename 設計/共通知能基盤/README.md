# 共通知能基盤仕様

本ディレクトリは、ARC2 / ARC3で共通利用するAGI三主体の設計正本である。

## 基底原則

- 基底言語は日本語とする。
- AGIの主体構成は `HDS + ミニドラ + 記憶` の三主体で固定する。
- HDSコンパイラは独立主体ではなく、HDSの管轄に属する。
- HDSが世界との入力・出力境界を保持する。
- ミニドラは計算主体であり、世界への最終作用を確定しない。
- 記憶は可変な判断根拠保持主体であり、単なる追記ログではない。
- ARC2 / ARC3固有差分はAdapterへ閉じ込め、共通知能基盤へ逆流させない。

## ミニドラの詳細正本

ミニドラ内部のLayer-0、命令形P、外部参照R、Runtime、完成判定、実装詳細は本ディレクトリで再定義しない。

正本は次のリポジトリを参照する。

- `https://github.com/gatchimuchio/NOTNN-LLM-MINIDORA`

本ディレクトリでは、AGI三主体へ接続するために必要な責任境界と入出力契約だけを固定する。

## 依存方向

```text
共通知能基盤
├ HDS
├ ミニドラ
├ 記憶
└ 三主体統合
        ↓
   Domain Adapter
     ├ ARC2
     └ ARC3
```

ARC側の都合でHDS、ミニドラ、記憶の本体仕様を分岐させてはならない。
