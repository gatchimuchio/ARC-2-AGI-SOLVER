# ミニドラ接続仕様書

## 0. 位置づけ

本書はミニドラ本体の内部設計を再定義しない。
AGI三主体において、ミニドラを **LLM計算主体** として接続するための境界仕様だけを定める。

ミニドラ内部の正本は次を参照する。

- `https://github.com/gatchimuchio/NOTNN-LLM-MINIDORA`

現在のミニドラ本体では、概念上の純粋計算主体を次で表す。

```text
C = L0 ⊗ P
```

Data / Knowledge は外部参照Rとして計算主体から分離される。
本書はこの構造をAGI三主体へ接続する。

## 1. AGI内での責任

ミニドラは次を担う。

- HDSがコンパイルした入力の計算
- 命令形の実行
- 参照されたData / Knowledgeの利用
- 仮説生成
- 反対仮説生成
- 関係合成
- 逐次計算
- 予測
- 計画
- 候補作用生成
- 結果候補形成
- HDS Feedbackを受けた再計算

ミニドラは次を担わない。

- 生のARC世界を最初に解釈する権限
- 現在目的を独断で変更する権限
- 記憶全体を無制限に参照する権限
- ARC世界への最終作用確定
- 正本記憶の独断更新
- HDSのGateを迂回したSelf-Commit

## 2. HDSとの接続

ミニドラが受け取るのは、世界そのものではなくHDSによって形成・監査・コンパイルされた入力である。

```text
ARC世界
  ↓
HDS
  ↓
HDS Compiler
  ↓
HDS計算要求パケット
  ↓
ミニドラ
```

HDS計算要求パケットには、少なくとも次が含まれ得る。

- 現在目的
- 成功条件
- 世界記述
- 観測境界
- 未閉包項
- 証拠境界
- HDSが許可した記憶参照
- 利用可能作用
- 資源予算
- 現在問い
- 計算要求
- 期待出力
- 反証条件
- 停止条件

ミニドラ側は、このパケットを自分のLayer-0 / P / Rへ接続して計算する。

## 3. Rとの関係

ミニドラ本体のRはData / Knowledgeを供給する外部参照層である。

AGI統合時は、Rへ与える参照範囲をHDSが統制する。

```text
HDS
  ↓ 検索条件・参照許可
記憶
  ↓ 許可済み記憶集合
R
  ↓
L0 ⊗ P
```

物理実装上ミニドラが検索処理を直接呼ぶ場合でも、論理上の検索目的・scope・許可集合・引用元はHDSが固定する。

## 4. Pとの関係

Pはミニドラ内部の命令形保持体であり、AGIの可変判断根拠記憶とは分離する。

```text
P_instr != M_mem
```

記憶内に命令形候補、定石、手続き候補を保持することはできるが、それをミニドラの有効Pへ昇格する場合は別の承認点を持つ。

HDSは「何を計算させるか」を決めるが、ミニドラ内部の命令形実装詳細はミニドラ本体仕様に従う。

## 5. 出力契約

ミニドラのAGI向け出力は最終回答ではなく、HDSへ返す **候補計算結果** である。

概念上の出力を次とする。

```text
ミニドラ候補パケット := {
  入力参照,
  使用記憶参照,
  仮説集合,
  反対仮説,
  推定構造,
  予測,
  計画候補,
  作用候補,
  no-op候補,
  各候補の成立条件,
  各候補の反証条件,
  未解決項,
  追加観測要求,
  停止候補,
  計算痕跡参照
}
```

必須の厳密schemaはミニドラ実装の成熟に合わせて別途固定する。本書では責任境界を正本とする。

## 6. 採否の二層分離

ミニドラ本体に存在する「採否・結果形成」と、AGIとしての外部作用Commitを混同しない。

```text
ミニドラ内部採否
= ミニドラ計算内の候補整理・結果形成

HDS Commit
= ARC世界へ作用させる最終採否
```

したがって、ミニドラ内部で一つの結果が選ばれても、その結果はHDS Gateを通るまで外部作用ではない。

## 7. Feedback再計算

HDSはミニドラ出力を監査し、必要なら次を返す。

- 反証
- 追加条件
- 観測差分
- 適用範囲修正
- 記憶参照変更
- 目的再固定
- 代替仮説要求
- no-op比較要求
- rollback候補要求
- 追加計算要求

```text
ミニドラ出力
→ HDS
→ Feedback
→ ミニドラ再計算
→ HDS再監査
```

この内部循環は、HDSがCOMMIT / SUSPEND / FAIL / STOPを確定するまで継続できる。

## 8. 日本語基底

ミニドラとの意味上の接続は日本語を正本とする。

- 計算要求
- 仮説
- 関係
- 定石名
- 記憶の意味
- 反証
- 失敗理由
- HDS Feedback

は原則日本語で保持する。

Python予約語、package名、外部API、ARC/Kaggle固定記号などはAdapter境界で原語を保持してよい。

## 9. 禁止事項

1. ARC観測をHDSを経由せずミニドラへ直結しない。
2. ミニドラ出力をHDSを経由せずARCへ直結しない。
3. ミニドラに正本記憶更新権限を与えない。
4. ミニドラ自身が生成した候補を無監査で採用しない。
5. ミニドラ本体の内部仕様をARC都合でforkしない。
6. 共通仕様側でLayer-0 / P / Rの詳細を二重管理しない。

## 10. 適合判定

次が成立すればAGI接続上のミニドラ境界は成立している。

- HDS入力パケットだけから計算を開始できる。
- 許可された記憶集合だけを参照できる。
- HDS Feedbackにより再計算できる。
- 候補出力をHDSへ返せる。
- ミニドラ単独ではARC世界へCOMMITできない。
- ミニドラ単独では正本記憶を書き換えられない。

ミニドラの性能・完成度・内部適合性は、ミニドラリポジトリ側の試験と完成判定を正本とする。
